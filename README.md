# MoMotors

M-Motors est une entreprise spécialisé dans la vente de véhicule d'occasion.
Suite à une étude de marché elle a décidé d'ajouter un nouveau service de location longue durée.
Dans ce but une refonte de l'application web a été lancé.
MoMotors est donc le projet de refonte de cette application.

## Technologies utilisées

### Backend

- FastAPI
- PostgreSQL

### Frontend

- Angular 19.1

### DevOpS

- Docker
